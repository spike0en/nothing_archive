# Licensing

The Nothing Archive project is multi-licensed to protect both the code and community contributions.

For a detailed breakdown of what each license covers, please refer to the following license files in the repository root:

- [MIT License](https://github.com/spike0en/nothing_archive/blob/main/LICENSE-MIT): Applies to the website source code under `website/` (excluding `website/docs/` content) and automation scripts under `scripts/`.
- [Creative Commons BY-NC 4.0](https://github.com/spike0en/nothing_archive/blob/main/LICENSE): Applies to the documentation files, recovery guides, and compiled firmware/OTA database index tables.
- Anti-AI Data Mining Reservation: Commercial generative AI model training, automated dataset scraping, and uncredited LLM data ingestion without explicit prior written authorization are prohibited under Creative Commons BY-NC 4.0 and EU TDM Article 4 reservation terms.
- Extraction Binaries: `ota_extractor` and supporting shared libraries under `bin/` are sourced from AOSP and Chromium under Apache License 2.0 and BSD-3-Clause terms. See [bin/README.md](https://github.com/spike0en/nothing_archive/blob/main/bin/README.md) for attribution details.
- OEM Firmware & Official Resources: Official OTA links, system APKs, device renders, wallpapers, 3D models, and user manuals remain the property of Nothing Technology Limited and are indexed for non-commercial recovery and hardware identification under nominative fair use.
- Project Branding & Visuals: Original logos, banners, animated graphics, and icons under `website/static/img/brand/` are proprietary to Nothing Archive and are not licensed for third-party reuse. Product renders and application icons under `devices/`, `accessories/`, and `apps/` belong to Nothing Technology Limited or third-party developers. See [website/static/img/README.md](https://github.com/spike0en/nothing_archive/blob/main/website/static/img/README.md) for directory-level details.

See [website/static/fonts/README.md](https://github.com/spike0en/nothing_archive/blob/main/website/static/fonts/README.md) for full licensing details.

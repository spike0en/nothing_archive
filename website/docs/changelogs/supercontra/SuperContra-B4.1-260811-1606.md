# SuperContra-B4.1-260811-1606

## Update changelogs
What's New in This Update  

### Camera Enhancements
🤳 Improved Dual-view Video by adding support for the recording light indicator.  
📹 Optimised auto exposure stability in the preview when recording with the front camera.  
🌃 Improved image clarity and colour balance for shots in night scenes.  

### General Improvements and Bug Fixes
🎙️ Essential Voice can now be triggered via the Ear (3) Super Mic while using the keyboard.  
🔍 Fixed an occasional issue where the search bar could disappear from the home screen after unlocking.  
🔔 Fixed an issue where incoming ringtones from third-party apps could be heard through in-game voice chat.  
⚡ Enhanced charging reliability for a more stable experience.  
⚙️ Enhanced overall system stability.  
🛡️ Updated to August 2026 security patch.  

## Notes
Your device may use more power and feel warmer during installation. Performance will return to normal after the update is complete.

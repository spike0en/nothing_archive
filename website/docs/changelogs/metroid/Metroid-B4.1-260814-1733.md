# Metroid-B4.1-260814-1733

## Update changelogs
What's New in This Update  

### Essential Voice Enhancements
🔡 You can now customise whether a long-press or a double-click of the Essential Key triggers translation or transcription while typing. Set it up in Settings > Intelligence toolkit > Essential Voice > Customise Essential Key.  
⌨️ Quick switch between translation and transcription is now available by long-pressing the icon on the keyboard.  
🎧 Essential Voice can now be triggered via the Ear (3) Super Mic while using the keyboard.  
🎙️ Optimised Essential Voice for a smoother performance.  

### General Improvements and Bug Fixes
✨ Gallery image editing now supports AI Eraser, helping instantly remove unwanted objects, pedestrians, or reflections with one tap.  
🎚️ Optimised the volume slider animation effect at minimum volume for a more fluid feel.  
🔗 Improved Bluetooth connection reliability during phone calls.  
⚙️ Enhanced overall system stability.  
🛡️ Updated to August 2026 security patch.  

## Notes
Your device may use more power and feel warmer during installation. Performance will return to normal after the update is complete.
